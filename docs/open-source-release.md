# 本地版发布检查

源码发布与在线部署是不同步骤。当前本机后端没有多租户访问控制，默认仅监听 127.0.0.1；不要改成公网监听来充当在线版。

## 可重复验证

```bash
npm ci
npm run build
npm run test:agent
npm run test:projects
npm run test:tidy
npm run test:backup
node scripts/test-agent.mjs tests/modelConfigs.test.ts
node scripts/test-agent.mjs tests/accountStorage.test.ts
.venv/bin/python -m unittest discover -s backend -p 'test_*.py'
```

浏览器验收：创建文字、图片、视频卡片，连线，修改后重新打开；导出含媒体项目，在另一浏览器导入，核对文字、媒体、连线、历史资产。验证媒体丢失和无效备份不会覆盖原项目。实际 AI 生成需要使用者自己的模型配置，单元测试不等于真实上游服务可用。

## 发布范围

`npm run package:source` 采用源码白名单，排除 `.env`、`.env.local`、`.local`、`.backups`、构建产物、依赖目录和内部工作记录；发现常见凭证模式会中止且不输出凭证。该扫描不能替代人工审查。禁止直接压缩整个工作目录发布。

发布前待确认：

- 已于 2026-09-21 选择 AGPL-3.0-only，LICENSE 使用 GNU 官方原文。
- 确认品牌 Logo 与其他公开素材有权分发。
- 在干净机器或环境中完成安装、备份恢复、配置模型后的实际生成验收。
- 复核依赖许可和安全更新，记录已知问题。

项目尚未上传 GitHub，也未部署在线版。未来在线版需要服务器鉴权、用户隔离、云存储、配额与成本控制。
